### D-2 — Fail-open non-finite / boolean thresholds and NumPy scalar blind spots in `mangomas.eval.gate`

- **Lane:** P1 regression + `tests/eval/test_gate.py`
- **Symptom:** `_score_reasons`, `_cost_reasons`, `_reliability_reasons`, and `evaluate_regression_gate` in `src/mangomas/eval/gate.py` fail OPEN (return `passed=True`) when `min_mean_score`, `min_pass_rate`, `min_pass_pow_k`, `max_mean_score_drop`, or `max_pass_rate_drop` is `NaN` (`< nan` / `> nan` evaluates `False`), accept `bool` (`True == 1.0`) for thresholds, do not guard `pass_rate` finiteness, and reject/mis-handle NumPy real scalars (`np.float32` / `np.float64`).
- **Root cause:** Threshold and metric finiteness checks used raw `math.isfinite` selectively on metrics only rather than normalizing every threshold and metric via the shared `mangomas.utils.json_path.finite_number` helper.
- **Fix:** Add `_normalize_threshold` + `finite_number` validation (with warning logs and fail-closed reasons) across `_score_reasons`, `_cost_reasons`, `_reliability_reasons`, and `evaluate_regression_gate`.
- **Guard:** `tests/regression/test_aqa_20261120_defects.py::test_d2_eval_gate_fails_closed_on_non_finite_and_bool_thresholds_and_accepts_numpy_scalars`
- **Status:** GREEN

### D-3 — NumPy scalar drops/crashes & boolean count bypass in `mangomas.eval.runner` and `mangomas.eval._serialize`

- **Lane:** P1 regression + `tests/eval/`
- **Symptom:** `_row_cost_usd` in `src/mangomas/eval/runner.py` drops `numpy.float32` / `numpy.int64` row costs (making `max_mean_cost_usd` blind); `EvalRunner.__init__` accepts `bool` (`True == 1`) for `parallelism` / `trials`; `_finite_only` in `src/mangomas/eval/_serialize.py` leaves NumPy scalars (`np.float32`, `np.float64('nan')`, `np.int64`, `np.bool_`) and non-dict `Mapping`s unconverted, crashing `json.dumps`.
- **Root cause:** Ad-hoc `isinstance(..., int | float)` / `isinstance(..., float)` checks instead of `mangomas.utils.json_path.finite_number` / `is_bool_scalar` and `numbers` ABCs.
- **Fix:** Reuse `finite_number` & `is_bool_scalar` in `runner.py` and `numbers` + `Mapping` + `finite_number` / `is_bool_scalar` in `_serialize.py`.
- **Guard:** `tests/regression/test_aqa_20261120_defects.py::test_d3_eval_runner_and_serialize_handle_numpy_scalars_and_reject_bool_counts`
- **Status:** GREEN

### D-4 — Boolean score coercion and large-int `OverflowError` in `mangomas.eval.scorers.llm_judge`

- **Lane:** P1 regression + `tests/eval/test_llm_judge.py`
- **Symptom:** `LLMJudgeScorer.score` coerces JSON `{"score": true}` to `1.0` (PASS) and raises uncaught `OverflowError` on 400-digit integer JSON scores (`10**400`) instead of raising `LLMBadResponse`.
- **Root cause:** `float(payload["score"])` accepts `bool` and only catches `(TypeError, ValueError)`.
- **Fix:** Reject `is_bool_scalar(raw_score)` as `"not numeric"`, emit structured debug log, and catch `(TypeError, ValueError, OverflowError)`.
- **Guard:** `tests/regression/test_aqa_20261120_defects.py::test_d4_llm_judge_rejects_boolean_and_overflow_scores`
- **Status:** GREEN

### D-5 — Boolean `timeout_seconds` acceptance in `mangomas.harness.repair_sandbox`

- **Lane:** P1 regression + `tests/harness/test_repair_sandbox.py`
- **Symptom:** `run_oracle_and_promote(..., timeout_seconds=True)` accepts boolean `True` as a 1.0s timeout instead of rejecting non-numeric booleans with `ToolExecutionError`.
- **Root cause:** Direct `math.isfinite(timeout_seconds)` allows `bool` subclasses without calling `finite_number`.
- **Fix:** Normalize `timeout_seconds` via `finite_number` (with warning log on invalid timeout) and update `MUT-SBX-07` in `scripts/guard_probe_manifest.json` in lockstep.
- **Guard:** `tests/regression/test_aqa_20261120_defects.py::test_d5_repair_sandbox_rejects_bool_timeout_and_accepts_numpy_real`
- **Status:** GREEN

### D-6 — Boolean `schema_version: true` bypass in `scripts/deploy_environment.py` (`scripts/_deploy_registry.py`)

- **Lane:** P1 regression + `tests/test_deploy_environment.py`
- **Symptom:** `parse_registry({"schema_version": True, ...})` accepts boolean `True` because `True == 1` (`SUPPORTED_SCHEMA_VERSION`).
- **Root cause:** `version != SUPPORTED_SCHEMA_VERSION` without `isinstance(version, bool)` guard.
- **Fix:** Reject `isinstance(version, bool)` in `parse_registry` (inside decomposed `scripts/_deploy_registry.py`) and re-export cleanly from `scripts/deploy_environment.py`.
- **Guard:** `tests/regression/test_aqa_20261120_defects.py::test_d6_deploy_registry_rejects_boolean_schema_version`
- **Status:** GREEN
