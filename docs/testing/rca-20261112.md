## Register

### D-1 — `mangomas eval -p 0` / `MANGOMAS_EVAL__PARALLELISM=0` bypasses `ConfigError` and leaks an unclosed `Orchestrator`

- **Lane:** Tier-5 No-mock E2E (`live_cli_adversarial_and_rag_ceiling_boundaries`).
- **Symptom:** Running `mangomas eval -p 0` builds an `Orchestrator`, fails inside `EvalRunner(..., parallelism=0)` with an uncaught `ValueError: parallelism must be >= 1; got 0` (exit `1` traceback), and never awaits `_runtime._close_orchestrator(orch)`.
- **Root cause:** `EvalSettings._validate_eval` (`src/mangomas/config/evaluation.py:280`) validates `trials < 1` and `schema_version < 1` but omits `parallelism < 1`. In `src/mangomas/cli/commands/eval.py:227-263`, `_run_eval_pipeline` rejects `effective_trials < 1` before building `orch`, omits the matching check on `effective_parallelism < 1`, and instantiates `EvalRunner(...)` outside `_run_eval`'s `try ... finally: await _runtime._close_orchestrator(orch)` guard.
- **Fix:** Validate `("parallelism", self.parallelism)` in `EvalSettings._validate_eval`; reject `effective_parallelism < 1` in `_run_eval_pipeline` with structured logging and `EXIT_CONFIG_ERROR` (`2`); and close `orch` if `EvalRunner(...)` raises before `_run_eval` begins.
- **Class:** D-n (`src/mangomas/config/evaluation.py`, `src/mangomas/cli/commands/eval.py`).

### D-2 — `mangomas rag query --top-k` ignores `MANGOMAS_VECTOR__MAX_TOP_K`

- **Lane:** Origin-delta CLI/RAG audit (`src/mangomas/cli/commands/rag.py:92`).
- **Symptom:** `Retriever` enforces `max_top_k`, but the CLI `rag query` command instantiates `Retriever(embeddings=embeddings, vector_store=vector_store, top_k=cfg.vector.top_k)` without passing `max_top_k=cfg.vector.max_top_k`, falling back to `Retriever`'s default `50` even when an operator configures a lower ceiling (e.g. `MANGOMAS_VECTOR__MAX_TOP_K=1`).
- **Root cause:** Missing keyword argument `max_top_k=cfg.vector.max_top_k` in `rag.py::query`.
- **Fix:** Pass `max_top_k=cfg.vector.max_top_k` when constructing `Retriever`.
- **Class:** D-n (`src/mangomas/cli/commands/rag.py`).

### D-3 — `EmbeddingSimilarityScorer` `_cosine_similarity` propagates `NaN`/`Inf` and lacks `[-1.0, 1.0]` clamping

- **Lane:** Origin-delta eval scorer audit (`src/mangomas/eval/scorers/embedding.py:36`).
- **Symptom:** Non-finite embedding components (`NaN`, `±Inf`) or overflowing dot products/norms produce `NaN`/`Inf` scores that poison aggregate eval reports; IEEE-754 drift slightly above `1.0` or below `-1.0` can produce out-of-range similarity scores.
- **Root cause:** `_cosine_similarity` checks `norm_a == 0.0 or norm_b == 0.0` without verifying `math.isfinite(...)` on inputs or products/norms, nor clamping `cosine` to `[-1.0, 1.0]`.
- **Fix:** Fail closed to `0.0` with a warning when any input element, dot product, or norm is non-finite (or zero norm), and clamp `cosine` to `[-1.0, 1.0]` before linear mapping to `[0.0, 1.0]`.
- **Class:** D-n (`src/mangomas/eval/scorers/embedding.py`).

### D-4 — Non-finite floats (`NaN`/`±Inf`) accepted across `json_field` scorers/predicates and `ToolPolicy` schemas

- **Lane:** Origin-delta structured-output & Ring-1 policy audit (`src/mangomas/eval/scorers/json_field.py`, `src/mangomas/workflow/predicate/{_json_field,_spec}.py`, `src/mangomas/harness/tool_policy.py`).
- **Symptom:** In `_as_number` (both `eval` and `workflow`), `float(nan)` / `float(inf)` is accepted as a numeric value (`isinstance(found, int | float)`), allowing non-finite numbers into numeric bounds checks and `equals`/`at_least`/`at_most` configuration. In `ToolPolicy`, `type: "number"` accepts non-finite floats, and union schema `type: [...]` lists bypass argument type validation completely.
- **Root cause:** Missing `math.isfinite` checks on numeric conversion and spec validation, plus `isinstance(expected_type, str)` without handling list unions in `validate_tool_arguments`.
- **Fix:** Enforce `math.isfinite` in both `_as_number` helpers and check bounds specs (`equals`, `at_least`, `at_most`); reject non-finite floats on `type: "number"` and validate list-form union `expected_type` entries in `tool_policy.py`.
- **Class:** D-n (`src/mangomas/eval/scorers/json_field.py`, `src/mangomas/workflow/predicate/_json_field.py`, `src/mangomas/workflow/predicate/_spec.py`, `src/mangomas/harness/tool_policy.py`).

### D-5 — `or {}` coerces falsy non-dict options/metadata and `mango_bridge` lacks agent-slug/timeout guards

- **Lane:** Origin-delta dataset/scorer & bridge audit (`src/mangomas/eval/scorers/composite.py`, `src/mangomas/cli/commands/_eval_config.py`, `src/mangomas/eval/dataset.py`, `eval_harness_bridge/src/{convert_dataset,mango_bridge}.py`).
- **Symptom:** Expressions like `row.get("metadata") or {}` or `entry.get("options") or {}` silently treat `[]`, `""`, `0`, or `False` as `{}` instead of raising a schema error. In `mango_bridge.py`, user/dataset-supplied `agent` values (`"../admin"`, `"chat?x=1"`, `""`) are interpolated unsanitised into `/agents/{agent}/invoke`, and non-positive or non-finite `MANGO_TIMEOUT` values are accepted without error.
- **Root cause:** Truthiness coercion via `or {}`, unvalidated URL path interpolation in `mango_bridge`, and missing finiteness/positivity validation on `MANGO_TIMEOUT`.
- **Fix:** Use explicit `None` checks (`val = {} if raw is None else raw`) before `isinstance(..., dict)` validation; validate `mango_bridge` agent slugs against `\A[A-Za-z0-9][A-Za-z0-9._-]*\Z`; validate `MANGO_TIMEOUT` (`math.isfinite(timeout) and timeout > 0.0`).
- **Class:** D-n (`src/mangomas/eval/scorers/composite.py`, `src/mangomas/cli/commands/_eval_config.py`, `src/mangomas/eval/dataset.py`, `eval_harness_bridge/src/convert_dataset.py`, `eval_harness_bridge/src/mango_bridge.py`).

### D-6 — `merge_gate_results` drops `judge_excluded` when `r0` is calibrated, and `load_baseline` accepts `bool`/`NaN` metrics

- **Lane:** Origin-delta eval gate & baseline audit (`src/mangomas/eval/gate.py`, `src/mangomas/eval/baseline.py`).

- **Fix:** Aggregate `judge_excluded = any(r.judge_excluded for r in present)` and pick the matching `judge_note`; validate mapping type and finite non-bool numeric `mean_score`/`duration_ms` in `_report_from_dict`.
- **Class:** D-n (`src/mangomas/eval/gate.py`, `src/mangomas/eval/baseline.py`).
